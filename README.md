## 👋 About Me

Hey! I'm **Kro** (`@its_me_kyro`), a curious tech enthusiast who enjoys exploring technology, experimenting with ideas, and learning how things work.

I'm not a professional developer. I'm still learning programming fundamentals, building my knowledge, and experimenting with different technologies.

- 💻 Learning **JavaScript, Python & TypeScript**.
- 🤖 Exploring **Discord.js** and Discord bot development.
- 🛡️ Working as a **Discord Community Manager**.
- 🎮 I enjoy playing **Among Us, Super Sus**, and other multiplayer games.
- 🔧 Interested in software, open-source projects and community management.
- 🐧 Planning to explore **CachyOS** in the future.
- 📚 Education comes first, so my activity may be limited sometimes.
- 🌱 Always exploring something new.

> "A curious mind never stops exploring."
