## 👋 About Me

I'm on a continuous journey of learning programming and building things along the way. I enjoy taking small ideas and turning them into functional projects.

- 💻 Learning **JavaScript, Python, and TypeScript**.
- 🌐 Exploring web development and building browser-based applications.
- 🔐 Interested in privacy, encryption, and useful software.
- 🤖 Exploring Discord.js and bot development.
- 🛡️ Working as a **Discord Community Manager**.
- 🎮 Enjoy playing Among Us, Super Sus, and other multiplayer games.
- 🐧 Interested in Linux and planning to explore **CachyOS**.
- 📚 Balancing technology, personal projects, and education.

### 🔐 MoonCrypt

**Private Text & File Encryption**

A browser-based encryption utility designed to protect messages, code, and files using password-based encryption.

- 🔒 AES-256-GCM encryption.
- 📝 Encrypt and decrypt text or code.
- 📁 Encrypt multiple files and entire folders.
- 📦 Export encrypted data as portable files.
- 🔐 Password-based encryption and decryption.
- 🌐 File processing happens locally in the browser.
